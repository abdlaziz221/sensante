# Métriques IA pour le Dashboard – Lab Dashboard v0.6

## Métriques KPI envisagées
- Nombre total de diagnostics IA
- Taux de diagnostics urgents
- Confiance moyenne des diagnostics

## Graphiques envisagés
- Répartition des niveaux d'urgence (camembert)
- Diagnostics par région (barres)
- Évolution des diagnostics par mois (courbe)

## Alertes
- Derniers diagnostics urgents (confiance > 60%)
- Consultations sans diagnostic depuis +24h
